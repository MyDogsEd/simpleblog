# Simple Blog Example

To run the project, run `npm start`

localhost:3000 is the home page, which displays all posts.
Click on the 'New Post' button to be taken to the new post page.
Once 'Submit' is clicked on the new post page, a POST request will be sent to
`/add`. When the post request is finished successfully, you will be redirected
to that post's page. If you now visit the home page (click on the logo in the
top left), you will see the post you have just made.
